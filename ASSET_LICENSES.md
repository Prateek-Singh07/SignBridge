# Asset Licenses and Attribution

This document details the source, author, licensing, and attribution for the ASL (American Sign Language) alphabet reference images bundled into SignBridge.

## Summary

- **Collection:** WPClipart ASL Fingerspelling Alphabet
- **Author / Editor:** Paul Sherman (WPClipart)
- **Source Repository:** Wikimedia Commons ([Category:ASL_letters](https://commons.wikimedia.org/wiki/Category:ASL_letters)) & [WPClipart](https://www.wpclipart.com/)
- **License:** Public Domain (PD / CC0 1.0 Universal equivalent)
- **Permissions:** Unrestricted worldwide public domain dedication. Free for personal, educational, and commercial bundling and redistribution in applications without royalties or copyright restrictions.
- **Asset Format:** Universal PNG image sets (@1x 200×200, @2x 400×400, @3x 600×600) on transparent square canvases with uniform hand scaling and high-contrast vector outlines.
- **Motion Indicators:**
  - **Letter J:** Includes pinky handshape with curved directional arrow tracing the standard ASL J motion.
  - **Letter Z:** Includes index finger handshape with zigzag directional arrow tracing the standard ASL Z path.
